Tower Defense Game: Strategy Design Pattern

Course: SE 340 Team: Hunter Palmer, Noah Blodgett, Michael Ryan

A 2D (bird's-eye view) tower defense game built in Unity to demonstrate the Strategy design pattern. 
Enemies follow a path toward the end of the map, and towers shoot them before they get there. Each tower can use a different targeting strategy to decide which enemy to shoot.

Tech
Unity 6.0
C#
2D, bird's-eye view


How to Open the Project
Install Unity 6.0 through Unity Hub.
Clone this repository:
bash
   git clone https://github.com/HunterPalmer7/SE340---Tower-Defense-Game-Strategy-.git
In Unity Hub, choose Add > Add project from disk and select the cloned folder (the one containing Assets/, Packages/, and ProjectSettings/).
